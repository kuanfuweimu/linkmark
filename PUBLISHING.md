# Release status / 发布状态

Linkcard 0.3.2 is distributed as a GitHub prerelease for manual development-plugin installation. Figma Community publication has not been completed. The old assets/ui-preview files depict a retired editor and must not be used to advertise 0.3.2.

Current development source is 0.3.5. The user confirmed Section paste in 0.3.3. Before publication, validate real 0.3.5 title clicks, font layout, locked-title interactions, legacy upgrades and undo, movement during loading, multiple links, page switching and helper restart. Disclose the running-plugin requirement, locked native title, raster background and optional Python helper. Do not claim always-on clipboard access or universal site support. Package an explicit file list, excluding temporary local diagnostic scripts.

Suggested listing: **Linkcard — Paste links into single-object preview cards.**
