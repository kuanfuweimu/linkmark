# Release status / 发布状态

Linkcard 0.3.0 is distributed as a GitHub prerelease for manual development-plugin installation. Figma Community publication has not been completed. The old assets/ui-preview files depict a retired editor and must not be used to advertise 0.3.0.

Before publication, validate real Figma paste detection, hidden worker execution, raster import, movement during loading, multiple links, undo/redo, page switching and helper restart. Disclose the running-plugin requirement and optional Python helper. Do not claim always-on clipboard access, universal site support or editable/clickable text layers.

Suggested listing: **Linkcard — Paste links into single-object preview cards.**

中文：本轮提供 GitHub 预发布版，未发布 Figma Community。正式发布前必须完成 Figma 实机验证。旧编辑界面预览资产已过时。需如实说明插件必须保持运行、卡片为单张图片及可选本机解析器。
